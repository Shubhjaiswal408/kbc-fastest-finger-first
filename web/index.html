Add a buzzer

  1. Flash KBC_BatteryC3 on an ESP32-C3 SuperMini (same file for every buzzer).
  2. Power it on. The blue LED blinks while it searches, then gives 2 long flashes.
  3. It appears here in a second as 🔋. Give it a student's name and a colour.
  4. For 15 s after power-on, press A-D: each tile turns green if its wire works.

Battery buzzers sleep between presses, so Blink is off for them: press a button and watch its LED instead.
