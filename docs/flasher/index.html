KBC Buzzer Flasher

Install the firmware on your ESP32 boards straight from this page. No Arduino IDE needed.

How to use: open this page in Chrome or Edge on a computer, plug the board in with a data USB cable, press Install on its card and pick the board's port. Takes about a minute. New here? Read the project page first.
Buzzer · one per student

Battery buzzer

ESP32-C3 SuperMini · firmware KBC_BatteryC3 v2.02

  1. Remove the batteries, then plug the C3 into USB.
  2. Not in the port list? It's asleep: hold BOOT, tap RESET, release BOOT, then try again.
  3. After installing, it searches for the host and gives two long flashes.
  4. For 15 s after power-on, press A-D: each tile on the Buzzers tab turns green.
This browser can't flash boards. Use Chrome or Edge on a computer. Open this page over https to flash.
One per room

Host

ESP32 dev board · firmware KBC_Host v1.3.1

  1. Plug the ESP32 into USB and press Install.
  2. Stuck on "Connecting…"? Hold the BOOT button until the install starts.
  3. Then join Wi-Fi KBC-Quiz (password kbc12345) and open http://192.168.4.1.
  4. School Wi-Fi: set it later in Settings → Host Wi-Fi.

Updating an existing host? Don't tick "Erase", or buzzer names, scores and questions are lost.

Troubleshooting

ProblemFix
No port in the listUse a data USB cable (some only charge). Battery buzzers sleep: hold BOOT, tap RESET, release BOOT.
Host board not detected at allInstall the CP210x driver (or CH340, depending on the board).
"Failed to connect" / stuck on connectingHold BOOT while the install starts. Close the Arduino IDE Serial Monitor and any other program using the port.
"Wrong chip"You picked the wrong card. The host needs an ESP32 dev board; the buzzer needs an ESP32-C3 SuperMini.
Install button says the browser isn't supportedUse desktop Chrome or Edge (Web Serial). Phones and Firefox/Safari can't flash.
Firmware is built from the KBC Buzzer repository (MIT license). The public host firmware contains no Wi-Fi password: set your school Wi-Fi in the host's Settings page. Flashing uses ESP Web Tools.
